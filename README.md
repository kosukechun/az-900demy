# AZ-900 問題集

公開URL: https://kosukechun.github.io/az-900demy/

Q1〜Q6の各70問と、提供された `mogimondai.pdf` の総仕上げ40問を基にしたQ7、計460問の学習アプリです。単一選択と複数選択のすべての問題を回答・採点できます。サーバー側のデータベースや外部ランタイム依存はありません。

## 演習と復習

- 単一選択はタップで判定。複数選択は選び終えてから下部の「回答する」で判定します。
- ホームの「誤答のみ」では全セットをまとめて、各セットの「間違えた問題のみ」ではそのセットだけを復習できます。結果画面からも開始できます。
- 正解した問題は未克服リストから外れます。復習開始時に対象を固定するため、途中で正解しても問題が飛んだり順番が変わったりしません。
- 「最初から解く」はそのセットの通常回答だけをリセットします。未克服リストと他セットの回答は残します。
- 回答、未克服リスト、復習中の回答、表示密度は同じ端末の同じブラウザーに保存します。PCとiPad間の同期はありません。
- 旧版の有効な回答は引き継ぎます。設問や選択肢を修正した17問は古い回答を無効にして再回答できます。

## 解説と出題内容

## iPadで使う

Safariで公開URLを開いてください。画面下部の「前へ」「回答する」「次へ」は固定表示します。既定はコンパクト表示で、「コンパクト表示／ゆったり表示」ボタンから切り替えられます。主な操作は48px以上のタップ領域を確保しています。

横幅1000px以上では、回答前は問題文と選択肢、回答後は問題と解説を左右に並べます。縦画面などでは1列になり、回答後に必要に応じて解説へスクロールします。長い問題や大きな文字ではスクロールが必要です。拡大操作は制限していません。

実機iPad Safariの動作は未検証です。この更新ではWindowsのブラウザー操作が接続先URLを確定できず停止したため、実ブラウザーでの表示確認も完了していません。データ検証と操作ハンドラーの自動テストは実行しています。

## ローカル実行・検証

Node.jsがあれば依存パッケージのインストールなしで実行できます。`index.html` を直接開くこともできます。

```powershell
npm start
```

ローカルURLは `http://127.0.0.1:4173` です。これはiPadからPCへ接続するURLではありません。

```powershell
python scripts/build_data.py
npm run check
npm test
npm run build
```

データ検証では全460問の回答、選択数、用語、修正問題の版番号、PDFとの対応、TXTと生成データの一致を確認します。操作テストでは全460問の正解操作に加え、誤答の抽出・復習中の順序・正解後の除外・保存と再読み込み・旧履歴の移行・セットのリセット・ストレージ不調などを検証します。実ブラウザーの描画テストではありません。

`dist/` には公開に必要なHTML、CSS、JavaScript、アイコン、問題TXTだけを出力します。

## 編集と公開

| ファイル | 用途 |
| --- | --- |
| `data/Q1.txt` 〜 `data/Q7.txt` | 問題文と選択肢 |
| `data/answers-Q1.tsv` 〜 `data/answers-Q7.tsv` | 正解、解説、参照資料キー |
| `data/glossary.tsv` | 用語、照合パターン、役割、参照資料キー |
| `data/reference-sources.json` | 追加の公式資料リンク |
| `data/content-meta.json` | セット別問題数、修正問題、確認日 |
| `data/questions.js` | Pythonで生成するブラウザー実行用データ |

正解表は `問題番号|正解番号|解説|参照資料キー` です。番号は1から始め、複数選択は `1,2`、複数の正解組は `1,5;2,5` と記述します。すべての問題に有効な正解が必要です。問題を変更したら `python scripts/build_data.py` で生成データも更新してコミットします。過去の選択肢と互換性がなくなる変更では、回答の版番号も更新します。

`main` にpushすると `.github/workflows/pages.yml` が検証・テスト・ビルドを実行し、GitHub Pagesへ公開します。PagesのSourceはGitHub Actionsを使用します。

- リポジトリ: https://github.com/kosukechun/az-900demy
- 公開状態: https://github.com/kosukechun/az-900demy/actions
- Pages設定: https://github.com/kosukechun/az-900demy/settings/pages

公開URLを再読み込みすると更新を取得します。同じURL・ブラウザーなら保存履歴を引き継ぎます。
